# Car Sales Analysis using SQL

## Overview
SQL analysis of a car sales dataset (157 records) using MySQL, covering sales, pricing, horsepower and resale value across manufacturers and vehicle types.

## Tools Used
- MySQL
- MySQL Workbench

## SQL Concepts Used
- GROUP BY, HAVING, ORDER BY
- CASE WHEN
- COALESCE
- Subqueries
- Aggregate functions (SUM, AVG, MIN, MAX, COUNT)

## Files
- `car_sales_analysis.sql`: all queries

## Key Findings
- Ford had the highest total sales (~1.85 million units), more than 2.5x the second-ranked brand, Dodge.
- Top 3 brands by sales: Ford, Dodge, Toyota.
